# cf-pc npm Packaging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the Cloudflare Pages cleanup script as `cf-pc`, a globally installable npm CLI that runs on Node 26 with no build step.

**Architecture:** The published bin is `dist/cf-pc.js`, built by `bun build --target=node` in `prepack`; the `.ts` source is development-only, since Node's type stripping does not work under `node_modules`. `package.json` wires the built file as a `bin` with a `node` shebang. Argument parsing moves from a hardcoded default project to a required `-p`, and gains `-k/--keep` and `--version`. Tests spawn the real CLI with `node:test` and are excluded from the tarball.

**Tech Stack:** Bun build output running on Node 26 (`node:util` parseArgs, `node:test`), npm. No runtime or build dependencies.

**Spec:** `docs/superpowers/specs/2026-11-18-cf-pc-npm-design.md`

## Global Constraints

- Package name: `cf-pc`. Version: `0.1.0`. License: MIT.
- `bin`: `{ "cf-pc": "./dist/cf-pc.js" }`; the bin is compiled JS with shebang `#!/usr/bin/env node`.
- `engines.node`: `>=26`. `type: "module"`.
- Tarball contains exactly `package.json`, `dist/cf-pc.js`, `README.md` — nothing else.
- Source stays TypeScript; `dist/` is generated by `npm run build` and never committed.
- No runtime dependencies, no dev dependencies. Bun is needed only to build before packing.
- Keep existing deletion behavior unchanged: pagination, newest-N plus live production, `force=true`, concurrency, spinner, color rules, exit codes.
- Only erasable TypeScript syntax (no enums, namespaces, parameter properties).

## Review Focus

- `cf-pc --dry-run` with `-p` omitted must fail with a usage error, not call the API with an empty project path.
- `--keep 0` must mean "delete everything except live production", not be rejected or interpreted as "keep all".
- `cf-pc --version` must print and exit 0 with no credentials in the environment; it has to run before the token check.
- Piped output (no TTY) must contain no ANSI escape sequences and no spinner control characters.
- After `npm i -g`, the command must run under Node 26 from an unrelated directory through the npm shim — not raise `ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING`, and not only work under `bun run`.

- [ ] **Step 1: Write the failing test file `cleanup/test/cli.test.ts`**

```ts
import { test } from "node:test";
import assert from "node:assert/strict";
import { spawnSync } from "node:child_process";
import { fileURLToPath } from "node:url";
import pkg from "../package.json" with { type: "json" };

const CLI = fileURLToPath(new URL("../cf-pages-cleanup.ts", import.meta.url));

function run(args: string[]) {
  return spawnSync(process.execPath, [CLI, ...args], {
    encoding: "utf8",
    env: { ...process.env, CF_API_TOKEN: "", CF_ACCOUNT_ID: "" },
  });
}

test("--version prints the package version without credentials", () => {
  const result = run(["--version"]);
  assert.equal(result.status, 0);
  assert.equal(result.stdout.trim(), pkg.version);
});

test("--help prints cf-pc usage and exits 0", () => {
  const result = run(["--help"]);
  assert.equal(result.status, 0);
  assert.match(result.stdout, /Usage: cf-pc/);
  assert.doesNotMatch(result.stdout, /\x1b\[/);
});

test("missing project is a usage error", () => {
  const result = run(["--dry-run"]);
  assert.equal(result.status, 1);
  assert.match(result.stderr, /-p, --project/);
  assert.match(result.stderr, /Usage: cf-pc/);
});

test("blank project is a usage error", () => {
  const result = run(["--project="]);
  assert.equal(result.status, 1);
  assert.match(result.stderr, /-p, --project/);
});

test("valid arguments reach the credentials check", () => {
  const result = run(["-p", "demo"]);
  assert.equal(result.status, 1);
  assert.match(result.stderr, /Missing CF_API_TOKEN or CF_ACCOUNT_ID/);
});

test("keep accepts zero", () => {
  const result = run(["-p", "demo", "--keep=0"]);
  assert.equal(result.status, 1);
  assert.match(result.stderr, /Missing CF_API_TOKEN or CF_ACCOUNT_ID/);
});

test("non-integer keep is rejected", () => {
  const result = run(["-p", "demo", "--keep=abc"]);
  assert.equal(result.status, 1);
  assert.match(result.stderr, /Keep must be/);
});

test("negative keep is rejected", () => {
  const result = run(["-p", "demo", "--keep=-1"]);
  assert.equal(result.status, 1);
  assert.match(result.stderr, /Keep must be/);
});

test("non-integer jobs is rejected", () => {
  const result = run(["-p", "demo", "--jobs=0"]);
  assert.equal(result.status, 1);
  assert.match(result.stderr, /Jobs must be a positive integer/);
});
```
